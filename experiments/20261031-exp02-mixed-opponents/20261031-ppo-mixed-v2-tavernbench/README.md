# 实验 02 TavernBench：V1 与 V2 best

由正式训练的 finalize.py 在独立整局测试和最佳权重留存完成后自动启动。
结果、逐题回答、来源摘要和官方评分写在本目录，模型仍在 runs，不上传权重。

使用与第一次相同的候选计划概率适配器和官方 eval 集。
V1 为本次训练起点，V2 为依据混合对手固定验证平均名次选出的 best。
适配器只将原生玩家可见观测送入网络，不启用循环筛选或价值／战斗搜索。
预测阶段拒绝读取 labels，全部回答封存并计算摘要后再调用官方 scorer。

分别报告纯策略分数与复用既有战斗模块的 combat256 分数，前者是模型对比主项；
后者的战斗模块完全相同，不能把这部分收益解释为 PPO 学到的能力。
未支持项目沿用官方分母及之前的评分协议，见 [protocol.json](protocol.json)。
这组结果不用于选择训练检查点。
