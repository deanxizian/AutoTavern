## 已确认的 V4 改动

| 项目 | V3 历史规则 | V4 准备规则 |
| --- | --- | --- |
| 普通操作成本 | Move／Freeze 每次 −0.0001 | 0 |
| 循环成本 | 每次状态返回额外 −0.0002 | 每次状态返回 −0.0002 |
| 循环范围 | 连续 Move／Freeze 片段 | 同回合全部非 End 动作，包含出牌／选择／取消和技能菜单往返 |

| 混合验证 | 随机／贪心 | 保留随机／贪心两组 |
| best 指标 | 混合随机组平均名次，越低越好 | 沿用 |

循环按返回已见完整可见状态判断，不按动作 ID 相同判断。
正常操作产生新状态时不扣循环成本；最终名次奖励仍为 `(9 - 2 * placement) / 7`。
未加入重复触发的提前结束、60 步触顶惩罚或主动 End 奖励。

## 暂沿用 V3 的草案参数

- 128 环境 × 1,024 步，每次 PPO 131,072 个样本。
- minibatch 8,192，16 个／PPO；microbatch 1,024，epoch=1，目标 200 PPO。
- LR warmup：3e-6 → 1e-5，前 5%；随后线性衰减至 5e-6。
- d=192、4 层；BF16 前向，FP32 权重／Adam；计划继承 V3 best 与 Adam。
- 暂沿用 2 固定 V1 + 3 固定 V2 + 2 脚本对手；模型来源路径与摘要从 V3 配置复制。
- 混合随机／贪心验证各 64 局／点：step=0、PPO50／100／150／200；独立评估各 128 局／条件。
- 固定对手均随机采样；只有学习者区分随机与贪心；混合阵容中的脚本席位保留。

这些继承项是草案，不代表用户已经为 V4 逐项重新确定，后续可以在 V4 内单独调整。
旧 V3 实验保持原来的奖励和四组评估协议。
