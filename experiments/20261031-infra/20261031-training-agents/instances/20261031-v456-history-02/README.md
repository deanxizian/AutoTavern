首来源是原 V3 PPO150 best（SHA-256 `c8856c03f234b06839c0b631454b95c63ecb53266310785d6e046bd8d8ce17a1`），
91 个 Adam 状态的历史计数均为 5600。后续学习者及冻结新对手都绑定本链路实际阶段 best；
PPO0 参与选模，不能用旧实例 V4、final、最大版本号或独立 test 赢家替代。
即使 V4 best 的权重仍等于 V3，冻结 V4 的协议仍来自 V4 实验，不能按权重哈希猜代际规则。

每阶段 128 环境 × 1024 步、minibatch 8192、microbatch 1024、epoch 1。
LR 全程 `1e-5`，无 warmup 或衰减；继承 Adam moments／历史时钟，阶段计数归零。
学习者和 V4+ 冻结对手采用全动作循环成本 0.0002、操作成本 0、三次闭环／第 61 请求判负。
冻结 V1/V2/V3 无这两种新提前判负，模型对手始终随机采样，所有神经前向 BF16。

逐实际逻辑席位保存独立历史，共享模型权重不共享计数。deferred 和被预算拦截的动作不执行。
预算拦截只跳过该席位，其余真实动作继续；同批循环／预算请求原生统一淘汰，沿用物理座位
tie-break，并逐局旋转座位。仅对手淘汰不重置学习者；所有淘汰后果结算后才提交真实 pending
learner 转移，正常决出第一的奖励只发一次。恢复同一可见状态也显式清除历史计数。

每阶段自己的固定池下，学习者随机／贪心各 64 局，在 PPO0/50/100 验证。
仅随机组平均名次严格降低替换 best，相等留较早；不同阵容的原始 val 不横比。
initial/best/final 独立每模式 128 局，只报告，不选模、不排弱、不决定扩展。
W&B 每阶段独立 run，`optimizer_step` 是阶段实际 Adam 次数，val 起点为 0。

只有 V4–V6 训练、独立评估和留存全完成，且没有未解决的运行、数值、规则、原生动作或
评估异常，才检查条件扩展。V6 选中 best 的随机开发验证若仍 100% 由自身循环／预算判负，
视为未解决训练问题，停在 V6；不能把对手先退导致的名次变化当作摆脱循环。
两个判负率必须存在、finite、各在 [0,1] 且合计不超过 1。此 gate 仅决定条件预算，不改 best。
证据落 `extension-gate.json`；不使用独立 test 或 Greedy 排名设置额外晋级门槛。

若 gate 通过，V7–V9 每阶段固定保护最新已完成版 2 席，对前一池中其余 5 个保留版本做一次
开发排名：固定参考 **2 V1 + 2 V2 + 2 V3 + 1 脚本**，学习者为受评候选，随机 BF16 各 64 局，
固定开发种子 `60000007`。候选按自己的实际 checkpoint 协议，旧三代不套 V4+ 判负。
移除平均名次最高者，同分移除较旧者，剩 4 个旧版各 1 席，加最新 2 席和脚本 1 席。
已移除版本不复活；不拿各代 val 或独立 test 排弱。封存的排名输入、来源哈希、种子、局数与
候选协议全部核对后可复用，故障接续只补未封存候选，不重新挑结果。
