# 独立 Actor 调度：1／2 个 bot-v1 对手

2026-10-31，北京时间。只做推理采样补测，不更新权重、不保存模型、不启动第二轮训练。

**增加到 2 个 bot-v1 后，短测采样耗时增加约 11.1%。** 按 100 次 PPO 的预算外推，
采样与 GPU 更新合计从约 89.3 分钟增至 96.8 分钟，增加约 7.4 分钟。
包含缓存、GAE、验证和保存的排期仍建议预留 2–3 小时；完整 TavernBench 另算。

## 设置与测量

复用 [独立 Actor 原型](../20261031-unified-actor-sampling/README.md)，RTX 5080，256 局并发、
4 个模拟器线程、2 个 Torch CPU 线程。学习者和固定 V1 都用 BF16 前向，权重及对外概率、
value、log-prob 保持 FP32。回合上限 60，操作／循环成本分别 0.0001／0.0002。

比较 6 脚本 + 1 固定 V1 + 1 学习者，与 5 脚本 + 2 固定 V1 + 1 学习者。
两个固定 V1 席位共用一个策略实例，与学习者分别合批，不为每个席位复制一份模型。
每组每局采集 128 个实际学习者决策，共 32,768 条；两个种子 43／44，各方案合计 65,536 条。
先预热，再按 1／2／2／1 顺序测量，计时包含观测、模拟器、推理、奖励和标量审计。

| 固定 V1 数 | 种子 | 学习者样本 | 采样耗时 | 样本／秒 |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 43 | 32,768 | 5.112 秒 | 6,410.5 |
| 2 | 43 | 32,768 | 5.579 秒 | 5,873.5 |
| 2 | 44 | 32,768 | 5.610 秒 | 5,840.7 |
| 1 | 44 | 32,768 | 4.961 秒 | 6,604.8 |

| --- | ---: | ---: |
| 65,536 条学习者样本耗时 | 10.073 秒 | 11.189 秒 |

固定 V1 的动作数量约翻倍，但通过更大的 batch 处理，GPU 调用次数并未翻倍。
各局状态不同，因此就绪角色数量与调用次数会不同；本测试不能用于比较策略强弱。

## 100 次 PPO 的时间外推

预算保持 256 局 × 1,024 步／PPO，每次 32 个有效 minibatch × 8,192 样本，
microbatch 1,024、梯度累积 8、epoch=1，共 26,214,400 个学习者样本、最多 3,200 次 Adam。

| 项目 | 1 个固定 V1 | 2 个固定 V1 |
| --- | ---: | ---: |
| 每次 PPO 采样 | 40.3 秒 | 44.8 秒 |
| 每次 PPO 的 GPU 更新 | 13.3 秒 | 13.3 秒 |
| 每次 PPO 上述两项合计 | 53.6 秒 | 58.1 秒 |
| 100 次 PPO 采样 | 67.2 分钟 | 74.6 分钟 |
| 100 次 PPO 的 GPU 更新 | 22.2 分钟 | 22.2 分钟 |
| 100 次 PPO 上述两项合计 | 89.3 分钟 | 96.8 分钟 |

公式：每 PPO 采样 = `262144 / 实测样本每秒`；更新 = `32 × 0.415409681 秒`。
GPU 更新复用 [BF16 microbatch=1024 测量](../20261031-bf16-mixed-precision/summary.json)，
不是本次执行了训练。这些合计不含 PPO 缓存写入、GAE、验证、独立测试、保存或 TavernBench。

只有每局 128 步的短测，尚未实测完整 1,024 步 rollout 或新调度的完整 PPO。
本次 GPU 短测没有终局；终局由下面的确定性轨迹测试覆盖。
不同席位配置会改变随机轨迹和每局动作数，未来训练后的速度也可能变化。

## 验证与复现

`tests/test_actor_sampling.py` 对 1／2 个固定角色 × 1／3 线程共 4 个设置全部通过。
每个设置对照新旧驱动的 540 个学习者 transition，检查完整前后观测、动作、奖励、终局名次、
episode 次序和最终原生存档，覆盖连续两段采样及至少 6 次终局。

真实 GPU 补测检查样本配额与归属、合法动作、FP32 有限标量、BF16 head 输出，
核对 V1 源文件和停止的第二轮 latest 权重摘要不变、无优化器更新、无新检查点。
第二轮仍为 `stopped_by_user`；后续默认对手数没有因本次比较而修改。

