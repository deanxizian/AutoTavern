# 混合对手 GPU 预跑

正式实验 02 启动前验证。固定真实 V1 作为源模型和 4 个冻结对手，另外 3 席为脚本。
执行 256 环境 × 128 学习者步 = 32,768 个样本，batch=8,192、microbatch=1,024、epoch=1。
只在内存中更新探针网络，不保存探针权重，正式阶段仍从未改写的 V1 开始。

[run.py](run.py) 验证继承权重完全一致、Adam 从零开始、学习者真实更新、冻结对手不变、
全部权重有限以及源模型文件摘要不变，并记录采样／更新耗时、GPU 峰值和对手决策数。
结果见 [results.json](results.json)。

第一次预跑在学习者淘汰后继续等待所有旧模型对手结束，记录在
[初次测量](attempts/before-early-reset/results.json)。
发现等待浪费后，改为学习者名次已确定就立即重置该局，终局奖励保留，
不再模拟不采集经验的剩余对手；最终结果使用这项改动重新测量。

```bash
.venv/bin/python -u experiments/20261031-infra/20261031-mixed-opponent-preflight/run.py
```

完整 Python 验证涵盖原生旋转席位跨线程复现、冻结等待中的游戏状态完全不变、
淘汰后正确返回新局、只计学习者样本、Adam 阶段重置、四条件评估和 W&B 平面指标。
整体耗时外推以小规模实测为参考，正式 1,024 步的对局分布与 KL 早停会使实际速度变化。
