# V1／V2／V3 同场比较

独立、固定预算 **256 个八人局**，每局 **2 脚本 + 2 V1 + 2 V2 + 2 V3**。
三版均使用验证选出的 best、随机采样、BF16 前向；FP32 权重与概率。
V3 训练已完成 200 次更新，按固定混合随机验证的平均名次选中 PPO150。
这里不使用对战结果重新选模，不更新权重、不使用动作筛选或战斗搜索。

## 口径

- 每版两个席位，256 局对应每版 512 次玩家参赛；脚本也是 512 次。
- 平均名次越低越好；吃鸡率为第一名次数／该组玩家参赛次数；前四率同理。
- 第一名占比为该组第一名次数／256，各组之和为 100%；与每席位吃鸡率区别报告。
- 名次胜率为同一局中新版席位比旧版席位名次靠前的比例，每对版本每局 4 对。
  这不是单次战斗胜率。
- 置信区间按整局做 10,000 次 bootstrap，不把同局席位当成独立对局。

## 运行方式

原生 BatchEnv 并行 64 局，每 lane 记录最先完成的 4 局，不按输赢决定停止时间。
角色交错，优先执行的版本随 lane 与 episode 轮转；物理席位由原生环境随机分配。
只在六个模型席位均有真实终局名次后收录该局。
两个脚本的名次集合由 1–8 去掉六个模型名次精确得到，不假定哪个脚本拿到哪个名次。
所有席位仍采用每回合 60 步上限；V4 的奖励与提前结束建议均不接入本次对战。

配置、模型路径与 SHA-256 见 `config.json`；逐局记录为 `games.jsonl`，结果为 `results.json`。
W&B 独立 run 与本地 journal 记录结果，不改旧训练曲线，不上传权重。

```bash
.venv/bin/python experiments/20261031-exp03-v2-continuation/20261031-match-2script-2v1-2v2-2v3/run.py
```

开始前使用已知名次的合成案例，核对了三版两两名次比较、吃鸡率与整局 bootstrap。
已有对战记录时脚本拒绝覆盖；下面是已完成的实测结果。
