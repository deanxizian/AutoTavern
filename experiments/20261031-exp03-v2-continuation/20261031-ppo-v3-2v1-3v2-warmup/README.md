## 训练配置

| 项目 | 设置 |
| --- | --- |
| 每局阵容 | 2 个原生脚本 + 2 个固定 V1 + 3 个固定 V2 + 1 个学习者 |
| 模型共享 | 固定 V1 共用一份，固定 V2 共用一份，学习者另有独立参数与优化器 |
| 席位 | 每局随机分配实际席位，学习者为调度角色 0 |
| 网络 | d=192，4 层，8 头，3,491,978 个可训练参数 |
| 采样 | 128 环境 × 1,024 步 = 131,072 个学习者样本／PPO |
| 更新 | minibatch 8,192，16 个／PPO，epoch=1 |
| 梯度累积 | microbatch 1,024，累积 8 次／Adam |
| 总预算 | 200 PPO，26,214,400 个新样本，最多 3,200 次新 Adam 更新，与上轮总预算相同 |
| 学习率 | warmup 起点 3e-6，峰值 1e-5，结束 5e-6 |
| Warmup | 总进度前 5%，即前 10 个 PPO、最多 160 次 Adam；之后线性衰减 |
| LR 更新时机 | 每次采样完成、PPO 更新开始前；同次 PPO 的 16 个 minibatch 使用相同 LR |
| 实际首个 PPO LR | 3.7e-6；第 10 个 PPO 达 1e-5，第 200 个 PPO 为 5e-6 |
| 精度 | 学习者和所有固定模型均 BF16 前向，概率、GAE、loss、权重、梯度、Adam 为 FP32 |
| 奖励 | 沿用上一轮：名次效用，Move/Freeze 每次 −0.0001，重复状态额外 −0.0002 |
| 动作上限 | 每个招募回合 60，不使用推理筛选器 |
| PPO | gamma=1，lambda=0.995，clip=0.2，target KL=0.05，梯度裁剪=1 |
| 损失系数 | entropy=0.002，value=0.5，placement auxiliary=0.1；不增加阶段 KL 锚定 |

Warmup 是本地新增设计，峰值由用户指定，不是论文表 7 的复现。
所有采样前向均不构建梯度图；只保存学习者转移，PPO 更新时才重新前向和反向。
对手按通用命名角色池配置，支持任意版本组合与席位数，模型控制席位总数不超过 8，剩余为脚本。
更新学习者不影响固定 V2，即使两者从同一 ZIP 初始化。

## 测评与产物

训练前及 PPO 50／100／150／200 做四组验证，每组每点 64 局：

- 2 固定 V1 + 3 固定 V2 + 2 脚本，学习者随机采样（选模条件）。
- 同一混合对手，学习者贪心；固定对手仍随机采样。
- 7 脚本，学习者随机采样。
- 7 脚本，学习者贪心。

所有模型前向为 BF16；每个混合结果显式记录对手版本和数量。
结束后用独立种子、各条件 128 局比较初始 V2、best、final；不使用这些结果重新选模。
独立评估完成后只保留本阶段带北京时间前缀的 best；原始 V1/V2 不删除、不提交 Git 或 W&B。
模型在 `runs/20261031-ppo-v3-2v1-3v2-warmup/`，记录在本目录。
在线运行链接和实际状态分别见 `wandb.json`、`experiment.json`、`progress.json`。

选模只使用混合随机组的 `val/mean_placement`，即最终名次的平均值，越低越好。
新值严格降低才覆盖 best；相同保留此前版本；step=0 的起点也可成为 best。
`val/first_rate`、`val/top4_rate`、`val/greedy_*`、循环和触顶率均只作观察，
独立 test 也不参与选模。详见 [关键测评指标](../../../docs/TRAINING_METRICS.md)。

新阶段入口使用 `--continue-stage` 保留 Adam；`--warm-start` 仍表示清空 Adam。
监督入口为本目录 `run.py`，只在收到训练授权后执行。
