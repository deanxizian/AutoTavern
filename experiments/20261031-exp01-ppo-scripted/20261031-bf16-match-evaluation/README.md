# 第一轮 best：FP32 与 BF16 的配对整局评估

用户希望用完整对局确认 BF16 推理是否损失实力。本评估不训练、不更新权重，
也不会重启已按用户要求停止的第二轮。
源模型为 `runs/20261031-ppo-small-100ppo-32minibatches/20261031-131146-best_model.zip`，
SHA256 `7173d82343fcc79742838c72725c582966a3c5b7c84e15014debea292f32de24`。

## 协议

- 两种精度分别测随机采样、贪心推理，共四种条件，每种 256 局，总计 1,024 个计分对局。
- 每局都是 1 个第一轮策略对阵 7 个原生脚本机器人，角色位置随机，不启用推理循环筛选器。
- 四个独立种子区块，每块 64 条游戏通道，各条件复用相同区块／通道／第 0 局。
  配对依据这些游戏标识，不依据对局结束顺序。
- FP32 基线允许 TF32，与既有正式配置一致；BF16 仅在神经网络 forward 使用 autocast，
  logits 转回 FP32 后计算动作概率，模型权重仍为 FP32。
- 两种精度使用相同模拟器和动作上限（60），诊断器只计数循环，操作成本和循环成本均为 0。
- 同一种子不强制轨迹相同：精度改变动作后，后续状态、游戏随机流消耗和采样轨迹可能分开。
- 用 10,000 次配对整局 bootstrap 给出 BF16 − FP32 差值的 95% 百分位区间。
  名次差值为正表示变差，前四率／第一名率差值为正表示改善。

FP32 实验包装器已与原始 `policy.predict` 在随机和贪心模式核对动作一致。
每条通道只计第 0 局；等待其他通道完成期间产生的新局不计分。
主指标为平均名次、前四率、第一名率；另外记录每局循环次数、动作数和强制结束回合比例。
这是一组 256 局配对样本的精度对照，不是对所有对手环境的强度保证。

## 完成结果

每种条件 256 局，均对阵 7 个脚本机器人；结果详见 [results.json](results.json)，
逐局配对、统计重算与权重完整性校验见 [verification.json](verification.json)。

| 模式 | 精度 | 平均名次 ↓ | 前四率 | 第一名率 |
| --- | --- | ---: | ---: | ---: |
| 随机采样 | FP32 | 1.9883 | 95.31% | 43.36% |
| 随机采样 | BF16 | 1.9258 | 95.70% | 44.14% |
| 贪心 | FP32 | 3.6484 | 64.84% | 29.30% |
| 贪心 | BF16 | 3.8398 | 62.50% | 25.00% |

差值均为 BF16 − FP32，95% CI 来自配对 bootstrap：

- 随机采样：平均名次差 `-0.0625`，CI `[-0.171875, 0.04296875]`；第一名率差 `+0.78` 个百分点，CI `[-3.90625, 5.46875]`。
- 贪心：平均名次差 `+0.1914`，CI `[-0.10556640624999991, 0.4921875]`；第一名率差 `-4.30` 个百分点，CI `[-10.546875, 1.953125]`。

这批随机采样没有显示掉分；贪心点估计变差，但两种模式上述区间均包含 0，
不足以认定稳定下降，也不能证明在其他对手环境下完全无损。
本次耗时约 139 秒，不含日志初始化；源模型与第二轮已保存检查点未修改。
