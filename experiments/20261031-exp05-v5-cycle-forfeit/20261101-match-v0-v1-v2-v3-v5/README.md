# V0／V1／V2／V3／V5 平衡八人局

用户于 2026-11-01 指定原生脚本改称 V0，并要求这五版对战。本次为独立评估，训练保持停止。

## 固定协议

- 八人局，每版至少一席。枚举五版中任选三版各补一席的 10 种阵容，各打 32 局。
- 总共 320 局，每版恰好 512 个玩家出场；每版在 192 局占两席，在 128 局占一席。
- V1／V2／V3／V5 使用事先保留的 best，随机采样、BF16 前向，FP32 参数、冻结权重。
- V0 为原生 `crates/taverngym/src/bot.rs`；不是随机动作基线，也没有模型检查点。
- 每种阵容原生并行 32 局，每 lane 只取首局，不按输赢挑局。随机物理座位，交错模型角色按 lane 轮换执行顺序。
- 所有版本都使用原生 60 步强制 End，不因重复或触顶提前判负；无动作过滤、战斗搜索或训练更新。
- 模型终局必须收到真实且互异的名次；V0 总体名次由 1–8 减去模型名次精确补齐。
- Top 1／Top 4 rate 分母为各版玩家出场数 512；Mean placement 越低越好。
- 每局冠军份额 `lobby_win_share` 分母为 320，不等同于玩家 Top 1 rate。
- 各版两两比较共 800 对，统计同局最终名次谁更靠前，不是单场战斗胜率。
- 95% 区间按整局、在各阵容内分层 bootstrap 10,000 次，使用名次和／出场数等比值，保留席位相关性。
- 本结果只适用于本次混合阵容和随机采样模式，不用于选模型、选训练对手或自动续训。
