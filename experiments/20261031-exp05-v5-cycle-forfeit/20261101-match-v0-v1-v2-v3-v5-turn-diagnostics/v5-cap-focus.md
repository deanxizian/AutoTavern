# V5 触顶专项分析

同轮320个八人局：V0/V1/V2/V3/V5各1–2席、十种平衡阵容各32局；V5共512次出场，随机采样、BF16，冻结权重。仅重算既有记录，没有新增比赛或改变60步预算。

V5观察到7496个招募玩家回合，2829个触顶强制End（37.74%）。触顶回合前60步平均构成：

| 动作类别 | 每个触顶回合前60步的平均次数 |
| --- | ---: |
| 移动随从 | 41.65 |
| 冻结/解冻 | 2.65 |
| 取消菜单 | 0.07 |
| 其余动作（买卖、出牌、选择、刷新、技能等） | 15.63 |

触顶前最后10步，移动占83.78%，冻结占5.63%。在938/2829个触顶回合（33.16%），最后一次其他类型操作之后，还有至少20步只做移动/冻结/取消。

## 具体例子与解释

游戏回合14、lineup=7、lane=17、V5 seat=2：60次全部是Move，接着强制End，没有买卖/出牌；该回合完整可见状态返回只检测到2次。
游戏回合14、lineup=4、lane=26、V5 seat=1：升级1次、冻结1次、移动58次，再强制End；完整可见状态返回0次。
代码中的Move只调整自家随从顺序，没有直接扣金币、加属性或发出事件；合理站位仍能影响战斗，不能将所有移动判为无效。
循环检测比较完整features/cards是否回到已见状态。不同站位排列不会命中；对手升级、血量/护甲等公开变化也可能令整体观测不相等。上次after与本次before不连续时会清空历史。对手阵容常规使用上次侦察快照，不能说对手实时移位本身必然影响观察。
因此4.53%的全观测返回占比不表示剩余95.47%的动作都有意义。现有hash无法拆出局部棋盘状态，也无法量化对手公共变化在本轮遮蔽了多少自身往返。

当前证据支持先诊断V5过多调位和缺少主动End的情况；不支持直接认定大量触顶都是60过严导致。正常有效操作确实也会被预算截断，但缺少触顶时金币、手牌及忽略预算的合法动作，无法判定损失多少。
若后续要改进策略或比较60/120，须使用独立开发协议而非根据本独立test挑奖励/阈值或选冠军。本轮不更改训练、奖励或动作限制。
