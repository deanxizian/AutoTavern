# 60 步预算与触顶回合审计

数据：同一轮320个八人局，V0/V1/V2/V3/V5各1–2席平衡轮换，每版512次出场；V1/V2/V3/V5随机采样、BF16。此处只分析已封存逐回合轨迹，没有重跑比赛、训练或修改上限。

共19064个玩家招募回合超过60，其中18401个（96.52%）恰好61步；这些回合最后一步均是End。其余62/63步来自待选菜单的Choose/Cancel之后再End。

## 原生代码口径

- actions.rs 的 apply 对所有成功动作计数，包含出牌、买卖、移动、选择、取消和End；失败动作回退计数。
- 普通招募动作做满60后，legal_mask只开放End。因此记录会有60次动作加1次End，共61。
- 待选菜单先处理Choose/Cancel，避免在选目标或发现等未完成菜单里硬结束，之后再End；本样本因此出现62/63。uncapped席位另有例外，本轮没有观察到其他越界普通动作。
- 达到60后不区分动作是否创造价值，也不区分正常操作或重复；有用动作同样会被截断。结束的是当前招募回合，未直接判负。

## 实际触顶与动作构成

| 版本 | 玩家回合数 | 触顶强制End回合 | 触顶比例 ↓ | 触顶回合前60步中移动/冻结/取消占比 |
| --- | ---: | ---: | ---: | ---: |
| V1 | 6763 | 4906 | 72.54% | 80.54% |
| V2 | 7090 | 5397 | 76.12% | 75.38% |
| V3 | 7633 | 5932 | 77.72% | 75.24% |
| V5 | 7496 | 2829 | **37.74%** | 73.95% |

V5在触顶前最后10步中，移动占83.78%，冻结占5.63%。移动/冻结本身可以是合法正常操作，但这说明触顶不能都解释为大量买卖出牌；哈希轨迹不能评价每次移动的战术价值。

V5有623个触顶回合未检测到完全相同可见状态的返回。不断移动形成新的阵容排列也可能消耗大量预算；零返回不能证明零无效动作。

一个V5零返回的触顶实例：第5回合，61步，移动45次、冻结4次、出牌5次、选择3次、DarkGift/买入/刷新/End各1次。它说明零状态返回也可能伴随大量位置调整，不能把全部零返回回合视为正常购买操作需要更多预算。

## 能否认定60过严

正常操作若需要超过60次原子决策，确实会被结束回合；一次出牌可能还需要选目标、发现等多个决策，所以60不等于60次完整买卖流程。
现有轨迹只有动作与状态哈希，未保留触顶时的金币、手牌、可继续操作清单或未受预算遮蔽的掩码。不能由此算出多少有效操作被挡，也不能认定60或120是最佳上限。
下一次若专门检验上限，应固定模型与阵容、比较60与较宽上限，并保存触顶前金币/手牌、完整游戏快照、忽略预算后的合法动作、后续动作类型和名次。先区分正常操作被截断与预算被重复/大量位置调整消耗，不仅看触顶率；此对照尚未执行。
