# 测评 Agent 与批量比赛

用户于 2026-11-01 要求增加专用测评角色，并明确：320 局应一起推进，每轮按模型批量推理。
“320G”在此次比赛语境中指 320 局。

角色为 `evaluator`，项目配置位于 [.codex/agents/evaluator.toml](../.codex/agents/evaluator.toml)，
可安装副本位于 [configs/agents/evaluator.toml](../configs/agents/evaluator.toml)。
按用户要求固定使用 `gpt-6.1-terra`、`medium`；以后用户说“测评 Agent”“评测 Agent”或“比赛 Agent”即可调用。
角色以冻结模型对战与核验为职责，不控制训练恢复或冠军替换。
配置格式依据 [OpenAI 官方 subagent 文档](https://learn.chatgpt.com/docs/agent-configuration/subagents)。

## 调用约定

例如：“让测评 Agent 把 V0、V1、V2、V3、V5 打 320 局。”

主 agent 读取角色的 `developer_instructions`，传入已有授权、版本与来源、实际阵容、模式、
种子、局数和停止条件，通过 subagent 工具调用或复用 `evaluator`。无法按角色名加载配置时，
显式将指令放入任务消息，并以不继承完整对话的方式传入 `model="gpt-6.1-terra"`、
`reasoning_effort="medium"`，不沿用父任务的模型设置。
若已有实例模型不符，用正确设置新建 subagent；无需新建独立 chat，也不为每个参赛模型创建一个 Codex agent。
仅创建角色或准备方案不启动比赛；已给出执行指令则在其预算内完成。

V0 为原生脚本；V1 起为训练模型。版本和席位从用户及上下文确定，未指定的模式沿用已约定的
随机采样、BF16。八人局的轮换阵容事先固定，公布各版总出场数。
独立 test 不选模或选训练池，开发评估需另行明确其用途。

## 全量并行的含义

指定 320 局时，320 局全部在同一个调度中，每轮执行：

1. 收集所有未结束局的 `ready` 席位与合法动作掩码。
2. 按同权重、输入协议、精度及选动作模式合并观测，跨所有阵容和环境分片调用模型。
3. 将结果按索引分发回原席位，执行当前轮环境推进。
4. 保存已结束局，剩余局进入下一轮；直到恰好完成指定局数。

每轮有推理和推进的同步点，不要求不同对局在同一个游戏回合，也不等待全部完整对局结束才继续。
不同模型分别批量调用；V0 直接由 Rust 脚本执行。模型冻结，使用推理模式，每个任务只加载一次。

原生 `BatchEnv` 的受控席位数在一个实例内固定。不同阵容若有 6 或 7 个模型席位，可建两个分片，
但两个分片必须共同参与上述每轮调度；同模型的 GPU batch 合并所有分片的就绪席位。
例如此前十种平衡阵容可分为 192 局六模型席位与 128 局七模型席位，合计仍为 320 局同时推进。
不能将每种阵容各 32 局串行跑完后，把累计完成 320 局描述成“320 并行”。

确有资源限制时先考虑切分推理 microbatch，保留 320 个环境在调度中；如仍需降低环境并发，
须报告证据、请求和实际并发与原因。固定总计 320 局时，已结束局停用，不额外补新局超预算。
完整八人比赛应收集全部受控模型席位的真实终局，不能按单学习者训练的提前重置方式采样。

## 验收与留存

- 固定来源检查点 SHA-256、规则、种子、模式、阵容配额和有限预算，历史配置及结果不覆盖。
- 检查跨分片合并和动作分发、合法掩码、真实终局、每版出场数，封存后独立重算 Top 1／Top 4／平均名次。
- 记录实际并发、每模型 batch 分布、推理与推进耗时、局/秒和显存峰值，不能只凭配置宣称已提速。
- 2026-11-01 用户要求重复与步数分布：新测评按玩家/回合保存动作数、回合边界、可见状态返回次数、连续返回峰值及强制 End 次数；分别汇总每局/每回合均值与 P50/P90/P95/P99，以及无返回玩家局比例。
- 统一使用 `all_actions` 可见状态返回作只读诊断，不改变被测策略或对局规则；动作 ID 重复不等同循环。可回放轨迹需动作序列、回合和前后可见状态哈希。
- V0 的步数/重复须从原生脚本执行处采集；历史未记录项填“未知”，不能用名次补集或模型总动作数推算。
- 多席指标按玩家出场数计算，置信区间按整局重采样；固定轮换阵容使用分层重采样。
- 保存逐局结果、本地汇总、核验记录和 W&B 链接；权重不上传、不提交。指标定义见 [TRAINING_METRICS.md](TRAINING_METRICS.md)。
