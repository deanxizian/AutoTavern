# 论文来源与本地阅读文件

AutoTavern 论文使用 arXiv `2610.33845v1`：

- [论文页面](https://arxiv.org/abs/2610.33845v1)
- [原始 PDF](https://arxiv.org/pdf/2610.33845v1)
- [原始 LaTeX 源文件](https://arxiv.org/src/2610.33845v1)
- [原始 HTML](https://arxiv.org/html/2610.33845v1)
- [Hugging Face 页面](https://huggingface.co/papers/2610.33845)

本机的下载文件和阅读版本位于 `docs/papers/2610.33845/`：原始 PDF、源文件压缩包、
英文 Markdown、中文 Markdown、中文 HTML 及图片。它们属于本地阅读产物，由 `.gitignore`
排除；本次整理不会删除这些文件。

仓库中的实现边界、参数和性能结果分别见 [训练说明](../TRAINING.md)、
[训练基础设施改进](../TRAINING_INFRA.md) 和 [实验索引](../../experiments/README.md)。
中文阅读版本和本地实现选择都不应当作论文原始配方。
